# nested-loops
Nested Loops Pattern

A beginner-friendly Python project that demonstrates how to use nested loops to print patterns.

📌 Description

This program uses:

An outer loop to control rows
An inner loop to print numbers from 1 to 9

The pattern is printed 9 times using nested loops.

🧠 Concepts Used

Nested Loops
for loop
range() function
print() with end=""

💻 Code

for x in range(1,10):
    for y in range(1,10):
        print(y, end="")
    print()
